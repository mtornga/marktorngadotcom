## The argument

Short-form video already won. When a process still requires reading, that process is written against a runtime that is being deprecated. Read This For Me is the shim: point a camera at any words and hear them back, four different ways, from a single capture.

## The build

One Cloud Vision `TEXT_DETECTION` call feeds two paths. The verbatim path never touches a language model at all. The explain path runs `gemini-3.5-flash-lite` against one prompt template whose only varying line is `LENGTH:` — short, medium, and long are otherwise byte-identical.

Median warm latency measured from production logs on the day of the talk: 562ms for OCR, 467ms for the explanation, 228ms for the first spoken sentence.
